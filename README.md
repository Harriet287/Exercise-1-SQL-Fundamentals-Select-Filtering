SQL Exercise 1 - Basic Qeurying

This exercise covers introductory SQL concepts including how to retrieve and filter data from a database.
It helps build understanding of how SQL is used to interact with relational databases.

TOPICS COVERED
-SELECT stattements
-WHERE clause
-Logical operators(AND, OR, NOT)
-Comparison operators(=, !=, <,>)
-Sorting data with ORDER BY

TOOLS USED
-MySQL/SQL Server/SQLite(depending on your setup)

OBJECTIVE
-To practice writing simple SQL queries to retrieve and filter data from a database effectively.
